# UI audit (Sun Nov 8)

Ben, 2:40 AM CT: "A lot of the UI elements are either not formatted right or the buttons are too big and block some text. When I switch between Cam A and Map it's a different UI, a lot of things overlap each other and just don't work."

Screenshots are from production (https://104-238-146-229.sslip.io) on the demo session A9TVAN and the scratch session 6DQPSX, at 1512x982 (Ben's laptop), 1280x800 and 393x852. They live in `web/screenshots/audit/`. `before-*` shots use GPU Chrome; `beforesw-*` use SwiftShader, because MapLibre draws nothing in headless GPU Chrome. The script is `~/Code/scratch/shotmatch-agents/ui-audit-work/shots.mjs`; it also lists every pair of viewport controls whose boxes intersect.

Owners: **studio** = web/src/studio (Studio thread), **geo** = web/src/layers (Geo thread), **simple** = web/src/simple (Simple thread), **ui** = web/src/ui, styles.css, web/src/nvidia, web/src/photon, web/src/spacetime (this audit).

The shared tokens are in `web/src/ui/tokens.css`: radius 6 px for controls and 10 px for panels, one button at 28, 36 or 44 px, the 11/13/16 type scale with 20 and 28 for Simple headings, a 4 px spacing grid, and one z-index ladder with corner slots per view.

Status at 8:17 AM CT: 43 of 46 fixed on production; 40 left on purpose; 45 and 46 left, fixed on dev but not deployed before the 9:00 freeze. Status: **open** until fixed and checked on production; then **fixed** or **left** with the reason.
